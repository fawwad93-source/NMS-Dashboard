Automatic Google Sheets Sync

Uses your read-only service account through GitHub Actions; no private credential is stored in the browser.
The hosted app normally reads nms-data.json, which GitHub Actions rebuilds from the NMS Daily worksheet using the GOOGLE_CREDENTIALS secret. The service account only needs Viewer access. “Direct Sheet Sync” is an optional browser fallback and only works while the sheet is publicly readable.

Manual / QuickBooks Export Import

Use this as a fallback, or for a future QuickBooks POS export workflow.
A direct QuickBooks POS integration depends on the exact report/export format. This version is ready for CSV imports; once you provide one raw QuickBooks POS export, the importer can be mapped to it.
Mobile app: this package is a Progressive Web App (PWA). After hosting it on HTTPS, open it on your phone and use Install App / Add to Home Screen. It will launch in its own app window and retain the last successfully synced data.
Automatic sync: GitHub Actions checks the NMS Daily sheet every hour and commits a new snapshot only when the data changes. The app keeps the last successful snapshot locally for offline/mobile use.
